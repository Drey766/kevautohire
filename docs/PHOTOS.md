# Photos

Local copies in `public/photos/`, set in `brand.photos` (`src/config/brand.ts`), resized to at most 1600px wide, so the site needs no extra image host. To replace one, overwrite the file or point `brand.photos` at a new file (use a **new filename**: image caches are keyed by the URL). Set a path to `""` to fall back to the logo's swoosh for that spot.
